# Licence correspondence

Evidence for the Phase 0 gate. One file per vendor conversation, named `YYYY-MM-DD-vendor.md`.

Record, without paraphrase:

1. Vendor, product, contact name and date.
2. The four questions sent (DATA_RIGHTS.md §4), verbatim.
3. The answer, verbatim, with the message ID or a saved PDF of the email.
4. Whether each of the four points is `yes`, `no`, or `unclear`.
5. Contract or order reference, permitted outputs, and expiry date.
6. Whether the answer came from support or from the contract itself — support email is weaker evidence than the licence schedule.

Rules:

- Never store raw quotes or vendor data files here.
- A verbal "aggregate is fine" is not enough: ask for the sentence in the order form or licence schedule.
- No purchase before points 1–4 are answered in writing.
- The `data` and `data availability` sections of the manuscript cite this folder, not the vendor's marketing page.

Once a file here satisfies R1–R8 in DATA_RIGHTS.md §1, close the matching `TBD-DATA` fields in `preregistration.md` §2–§6 and §14, then freeze and tag `v0-preregistered`.
