# Drafts — not sent

These are **prepared, unsent** request letters. They are not correspondence and
not evidence. When a letter is sent, the reply is recorded in the parent folder
as `YYYY-MM-DD-vendor.md`, following [../README.md](../README.md).

Do not edit a draft after it has been sent: start a new dated file instead, so
that the parent folder keeps one file per conversation.
